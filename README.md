# المرشد الأكاديمي الذكي · جامعة بوليتكنك فلسطين (كلية ITCE)

**IEEE RAG Hackathon · Bethlehem University (BinX Tech × IEEE BU) · 7 نوفمبر 2026**

مساعد أكاديمي بيجاوب طلاب كلية تكنولوجيا المعلومات وهندسة الحاسوب عن أسئلتهم (بالعامية أو الفصحى) **من مستندات الجامعة بس**،
مع **المصدر** (المستند + الصفحة/المادة)، وبيرفض بوضوح لما المعلومة مش موجودة وبيحوّل الطالب للجهة المختصة.

---

## 1. المشكلة
المعلومة الأكاديمية موجودة، بس مبعثرة بين دليل الكلية، وتعليمات البكالوريوس، وجداول الخطط الدراسية لكل تخصص وكل سنة خطة.
الطالب بيسأل بلهجته («شو بصير إذا غبت كتير؟»)، والمستندات مكتوبة بالفصحى وبجداول، وكثير منها بنسخ متعددة (خطة 2022 / 2025).
الجواب الغلط ممكن يكلّف الطالب ساعات ضايعة أو فصل إضافي أو إنذار، ودوائر التسجيل بتضيع وقت كبير بأسئلة متكررة.

## 2. الحل
نظام **RAG** (Retrieval-Augmented Generation):
1. بنقرأ المستندات وبنقطّعها حسب **هيكلها** (مساق = سجل، مادة قانونية = مقطع، قسم = مقطع).
2. لكل سؤال بنسترجع أقرب 4 مقاطع (بحث بالكلمات + إعادة ترتيب ذكية حسب البرنامج/السنة/المساق).
3. الموديل اللغوي بيصيغ الجواب **من هالمقاطع بس**، مع رقم مصدر `[n]` بعد كل معلومة.
4. إذا ما في معلومة كافية: رفض ثابت + تحويل للجهة المختصة. وإذا في جزء من الجواب: بيعطي الموجود وبيحكي شو الناقص.

## 4. المعمارية
```
data/raw/ (PDF + MD)
  │
  ├─ src/chunking.py   PyMuPDF: نص + جداول (كل خلية لحالها، من اليمين لليسار) + أحجام الخط للعناوين + رقم الصفحة
  ├─ src/cleaning.py   3 نسخ لكل نص: raw (أصلي) / display (للعرض) / search (للبحث)
  │                    إصلاح لام-ألف المقلوبة («ال يجوز» → «لا يجوز»)، بدون حذف أي نفي أو شرط
  ├─ chunks            مساق = سجل ذرّي (رمز + اسم + ساعات + كل أعمدة الجدول + برنامج + سنة خطة + صفحة)
  │                    صف جدول عام = سجل · جدول كامل · قسم مرقّم · مادة قانونية · مجموعة خطة
  ├─ src/embedding.py  intfloat/multilingual-e5-small → ChromaDB (اختياري) + BM25 على search_text
  │
سؤال الطالب
  ├─ backend/api.py    cache للأجوبة · أسئلة المتابعة · فلتر خارج النطاق · سجل الأسئلة
  ├─ retrieval         BM25 (+ قاموس مرادفات للعامية) → RRF → reranking حسب البيانات الوصفية → Top-4
  ├─ src/generate.py   prompt صارم + مثال جواب (few-shot) → Groq qwen/qwen3.8-27b → فحص الأرقام
  └─ frontend/         Next.js: صفحة كتاب 3D · شات RTL · «من وين جبت الجواب؟» · لوحة إدارة
```
تفاصيل قرارات الـ pipeline والمشاكل اللي لقيناها بالـ PDF: [docs/DATA_PIPELINE.md](docs/DATA_PIPELINE.md)

## 5. الميزات

### الأساسية (المطلوبة)
- **استيعاب وتقطيع وتخزين** ملفات PDF و Markdown، بأمر واحد (`ingest_ppu.py`)، مع تقارير جودة.
- **استرجاع** أنسب 4 مقاطع لكل سؤال.
- **توليد** جواب من المقاطع المسترجعة فقط (temperature = 0، قواعد صارمة).
- **المصدر** في كل جواب: اسم المستند + الصفحة + القسم/المادة، وقابل للضغط بالواجهة.
- **رفض بدون اختراع**: جملة رفض ثابتة + تحويل لعمادة القبول والتسجيل؛ وفلتر للأسئلة خارج النطاق.
- **فهم العامية الفلسطينية**: قاموس مرادفات محكوم للبحث فقط (غبت ← الغياب، أسحب ← الانسحاب، أنزل مادة ← التسجيل…).

### الإضافية (ترفع العلامة)
- **تقييم بأسئلة اختبار وقياس الدقة**: تقييم الاسترجاع (32 سؤال) + تقييم الأجوبة الكامل + مقارنة موديلات (القسم 7).
- **بحث هجين + إعادة ترتيب**: BM25 + vectors (اختياري) مدموجين بـ RRF، ثم reranking:
  مطابقة رمز المساق الحرفية أولاً · تعزيز المساق المذكور اسمه · تنزيل المقاطع من برنامج غير اللي سأل عنه الطالب ·
  فلترة حسب البرنامج لأسئلة «شو المتطلبات…» · تنزيل المقاطع اللي هي قوائم أسئلة بدون أجوبة.
- **تذكّر سياق المحادثة وأسئلة المتابعة**: «وإذا كنت بالفصل الأخير؟» بيتوصل تلقائياً بالسؤال اللي قبله.
- **الجمع بين أكثر من مستند** بجواب واحد، مع `[n]` لكل معلومة من مصدرها.
- **شرح بخطوات أو قوائم** عند الحاجة (إجراءات مرقّمة، قوائم مساقات: الرمز — الاسم — الساعات).
- **عدم الخلط بين النسخ**: كل سجل معه البرنامج وسنة الخطة (2022 ≠ 2025)، والسنة غير المكتوبة بالمصدر ما بتنخمّن.
- **جواب جزئي صادق**: إذا الموجود جزء من الجواب، بيعطيه وبيحكي شو الناقص بدل الرفض الكامل.
- **فحص الأرقام**: أي رقم بالجواب مش موجود حرفياً بالمصادر بيطلع جنبه تنبيه للطالب.

### المنتج (البونص)
- **موقع كامل يعمل**: Next.js 15 + React 19، عربي RTL بالكامل، متجاوب مع الموبايل.
- **صفحة رئيسية 3D**: كتاب «دليل الطالب» بشعار الجامعة بيفتح وبتقلّب صفحاته مع الـ scroll، وأغراض جامعية عايمة حوله (React Three Fiber).
- **الشات**: لوحة «من وين جبت الجواب؟» فيها النص الأصلي لكل مصدر، وأسئلة مقترحة، وحفظ المحادثات بالمتصفح.
- **cache للأجوبة**: السؤال المكرر = جواب فوري (0 ms) بدون أي tokens. الرفض ما بينحفظ، والـ cache بيتصفّر لحاله لما تتغيّر المستندات.
- **لوحة إدارة `/admin`**: عدد الأسئلة، نسبة الأجوبة من الذاكرة، متوسط الزمن، **الأسئلة الأكثر تكراراً**، **الأسئلة المرفوضة** (فجوات بالمستندات)، والمستندات المفهرسة.
- **تحمّل الضغط**: إعادة محاولة تلقائية بانتظار متزايد عند حد الطلبات (429)، ورسالة «النظام عليه ضغط هلأ» بدل ما يوقع.

## 6. التشغيل (Windows)

### المتطلبات
- Python 3.12
- Node.js 20+ (جرّبناه على Node 26)
- مفتاح Groq مجاني من https://console.groq.com → API Keys

### الـ backend (من مجلد المشروع الرئيسي)
```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
```
افتح `.env` وحط مفتاحك بعد `GROQ_API_KEY=` (الموديل الافتراضي `qwen/qwen3.8-27b`).

```bash
.venv\Scripts\python ingest_ppu.py
```
بيقرأ كل ملفات `data/raw/` ← مقاطع ← (embeddings + ChromaDB) ← تقارير في `data/reports/`.

```bash
.venv\Scripts\python tests\test_pipeline.py
```
```bash
.venv\Scripts\python eval\ppu_eval.py
```
```bash
.venv\Scripts\python -m uvicorn backend.api:app --port 8000
```
(اختياري قبل العرض) تسخين الـ cache بالأسئلة الشائعة:
```bash
.venv\Scripts\python scripts\warm_cache.py
```

### الواجهة (بنافذة تانية)
```bash
cd frontend
npm.cmd install
copy .env.example .env.local
```
افتح `frontend\.env.local` وخلّي السطر: `NEXT_PUBLIC_RAG_API_URL=http://localhost:8000`
```bash
npm.cmd run dev
```
افتح http://localhost:3000 (الصفحة الرئيسية) · http://localhost:3000/chat (الشات) · http://localhost:3000/admin (لوحة الإدارة).

> إذا PowerShell رفض `npm` بسبب execution policy، استعمل `npm.cmd` زي فوق.
> بدون `.env.local` الواجهة بتشتغل بـ **وضع تجريبي** بأجوبة جاهزة (للتصميم فقط).

### أوامر مفيدة
| الأمر | شو بيعمل |
|---|---|
| `python ingest_ppu.py --dry-run` | تقطيع + تقارير بدون embeddings |
| `python ingest_ppu.py --reset` | إعادة بناء مجموعة ChromaDB من الصفر |
| `python ingest_ppu.py --ask "سؤال"` | يعرض أول 5 مقاطع للسؤال (فحص الاسترجاع بدون LLM) |
| `python eval\answer_eval.py` | تقييم الأجوبة كاملة مع الموديل (بيستهلك ~14 طلب) |
| `SEARCH_MODE=hybrid` بـ `.env` | تفعيل البحث الهجين بالـ vectors |

### إضافة مستند جديد
حط PDF أو ملف `.md` بـ `data/raw/` (للنصوص الرسمية: front matter فيه `title` و `source_url`، وكل مادة/مجموعة تحت `## `)،
وبعدين `python ingest_ppu.py` وأعد تشغيل الـ backend. الـ cache بيتصفّر لحاله.

⚠️ أسئلة التحويل والخطة كُتبت بعد قراءة نصوصها، فهي بتثبت إنه المصادر الجديدة بتنلاقى، مش اختبار أعمى. 32 سؤال عينة صغيرة.

## 9. حدود معروفة
- دليل الكلية نسخة بحثية مجمّعة مش قرار رسمي؛ المرجع النهائي خطة الطالب وقرارات عمادة القبول والتسجيل (والنظام بيحكي هيك).
- الخطط الكاملة مضافة لـ **هندسة الحاسوب 2025 فقط**؛ باقي التخصصات من عينات الدليل. صفحة الخطة ما بتذكر عدد الساعات المطلوب من المجموعات الاختيارية.
- المتطلبات السابقة موجودة لأمثلة من خطة IT 2022 فقط (صفحة 18).
- 43 مساق بالدليل بدون سنة خطة مكتوبة: تُركت `0` ولم تُخمَّن.
- الحد المجاني لـ Groq ممكن يبطّئ الجواب تحت ضغط عالي (الكود بيستنى وبيعيد المحاولة).

## 10. الأمان والخصوصية
